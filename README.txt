XAUUSD PRO V4

Android/GitHub Pages:
1. Extract ZIP.
2. Upload index.html, app.js, style.css and manifest.json to your repository root.
3. GitHub Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Open the generated github.io URL.
5. Settings ⚙️ -> paste Twelve Data API key -> Save & Load.

Features: live XAU/USD chart, EMA20/50/200, RSI, MACD, ATR, BUY/SELL/WAIT signal, confidence, Entry/SL/TP1/TP2 and mobile UI.
Signals are technical calculations, not guaranteed results. For production, use a server-side API proxy so the API key is not exposed.
